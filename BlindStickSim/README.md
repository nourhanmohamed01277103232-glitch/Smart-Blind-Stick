# Smart Blind Stick — Simulation + Phone App

## التشغيل
```
pip install -r requirements.txt
```
- اضغطي دبل كليك على `start.bat` (بيفتح الموبايل وبعده السيميوليشن)
- أو يدوي: `python phone.py` في تيرمنال، وبعدين `python sim.py` في تيرمنال تاني.

الترتيب مش مهم خلاص: السيميوليشن بيعيد المحاولة كل ثانية لحد ما الموبايل يفتح.

## أزرار السيميوليشن
| الزرار | الوظيفة |
|---|---|
| الأسهم | تحريك الشخص وتدوير العصاية |
| R | رجوع لنقطة البداية |
| N | تشغيل/فصل الضوضاء على الحساس |
| F | محاكاة السقوط (بيبعت تنبيه للموبايل) |
| F11 | ملء الشاشة |
| Esc / Q | خروج |

## إزاي الصوت بيشتغل
1. أول ما الحساس يلاقي أي عائق (لحد 200 سم) الصوت بيتنطق **فوراً** — مش مستني مسافة 180.
2. الجملة **كاملة زي المكتوبة**: «احذر! يوجد سيارة على بعد 120 سنتيمتر».
3. المسافة بتتقرب لشرائح 20 سم، والرقم ده **هو نفسه** اللي بيظهر على شاشة المحاكاة،
   وعلى التليفون، واللي بيتنطق — فمفيش أي فرق بينهم.
4. **مهم:** الجملة طولها ~4.5 ثانية، فلو نطقناها وأنتِ بتتحركي الرقم اللي بيتقال يخلف
   اللي على الشاشة (الشاشة تكون وصلت 60 والصوت لسه بيقول 140). عشان كده:
   - عائق جديد → نطق فوراً بالرقم المكتوب في اللحظة دي.
   - وأنتِ بتقربي → البيبة هي اللي بتقولك إنك قربتي (بتسرّع).
   - أول ما الرقم **يثبت 0.35 ثانية** (وقفتي أو بطّأتي) → ينطق الرقم المكتوب بالظبط.
5. لو المسافة اتغيرت أكتر من مرة وهو بيتكلم، بينطق **آخر رقم** بس (مش طابور أرقام قديمة).
6. ملفات الصوت بتتخزن في `voice_cache/` — بعد أول مرة بتشتغل بدون إنترنت وفوراً.

## إعدادات الصوت في `config.json`
```json
"voice": { "pc": true, "phone": false }
```
- `pc`: السيميوليشن هو اللي بيتكلم.
- `phone`: تطبيق الموبايل بيتكلم كمان.

خليكي على واحد بس شغال، لأن الجهازين على نفس اللابتوب فالصوت بيبقى مكرر
(ده كان سبب إن الصوت "بيتكّر").

## الملفات
- `sim.py` — السيميوليشن (pygame).
- `phone.py` — تطبيق الموبايل (tkinter).
- `stick_link.py` — الاتصال بينهم بإعادة محاولة تلقائية.
- `stick_audio.py` — تقريب المسافة + توليد/تخزين/تشغيل الصوت.
- `config.json` — البورت، الإحداثيات، توكن تليجرام، إعدادات الصوت.
- `voice_cache/` — ملفات الصوت الجاهزة (تتحذف لو عايزة تتولد من جديد).
- `log.csv` — لوج التنبيهات من السيميوليشن.
- `sent_alerts.txt` — الرسائل الطارئة اللي اتبعتت من التطبيق.
- `tests/` — اختبارات.

## تشغيل الاختبارات
```
python -m unittest discover -s tests -t .
```
